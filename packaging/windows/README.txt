Spotless @VERSION@ for Windows
A minimal Spotify player in the spirit of Winamp. It needs Spotify Premium.

Install
  Run install.cmd. It installs Spotless for you only (no administrator
  needed) and adds it to the Start menu.

  Or don't install it: Spotless.exe runs from anywhere on its own.

  Spotless isn't signed, so Windows may say "Windows protected your PC" the
  first time: choose "More info", then "Run anyway".

Update
  Spotless says when a newer release is out and, once you agree, installs
  it (F10, About). Running a newer release's install.cmd updates it too.

Uninstall
  Settings > Apps > Installed apps > Spotless > Uninstall, or run
  uninstall.cmd. Your settings, playlists and sign-in are kept in
  %APPDATA%\spotless; delete that folder to remove them too.

Keys
  F1 lists the keys, F10 opens the settings. Closing the window keeps
  Spotless playing in the tray; Ctrl+Q quits.
